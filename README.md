# В единстве — сила

«Своя игра» ко Дню народного единства для студентов. Один раунд: 20 вопросов из файла «Вопросы.docx», 5 тем, стоимость вопросов — 100, 200, 300 и 400 баллов. Всего на поле 5000 баллов.

## Запуск

На **macOS или Windows** дважды нажмите **«Игра.html»** и откройте его в современном браузере: Safari, Chrome или Edge. Установка и интернет не нужны: вся игра находится в одном файле, его можно скопировать на другой ноутбук. **«Запустить игру.cmd»** — дополнительный способ запуска только для Windows.

Исходная версия — **index.html**; для неё нужны находящиеся рядом `styles.css`, `questions.js`, `game-core.js` и `app.js`. После изменения исходников выполните `npm run build`, чтобы обновить автономный файл «Игра.html».

Для запуска через локальный сервер при установленном Node.js выполните `npm start` и откройте `http://127.0.0.1:4173`. Загрузка зависимостей не требуется.

В верхней части окна ведущего можно выбрать оформление: **«Светлая»** или **«Классика»**. Классическая тема — синее поле, белые названия категорий и жёлтые баллы, как в телевизионной игре. Тема сохраняется в браузере и автоматически применяется к экрану проектора. Переключать её можно до начала или во время игры; счёт и сыгранные вопросы сохраняются.

## Как провести игру

1. Введите названия от 2 до 8 команд и начните игру. По умолчанию неверный ответ не уменьшает счёт. При желании включите штраф перед началом: за ошибку будет списываться стоимость вопроса.
2. Выберите на поле тему и стоимость вопроса.
3. Выберите отвечающую команду и отметьте, верно ли она ответила. Правильный ответ приносит стоимость вопроса. После ошибки или пропуска команды вопрос можно передать другой команде.
4. Откройте правильный ответ кнопкой ведущего, когда это необходимо. После верного ответа он появляется автоматически. Можно пропустить весь вопрос без начисления баллов.
5. Вернитесь на поле и продолжайте раунд. Ошибочное действие можно отменить.
6. После раунда завершите игру: на экране появится команда с наибольшим счётом. При равенстве очков будут показаны все победители.

Игра автоматически сохраняется в этом браузере. После случайного закрытия страницы откройте её снова и продолжите. Для сохранения используйте тот же файл в той же папке, тот же браузер и обычный режим, а не приватное окно. Очистка данных браузера удаляет сохранение. Кнопка «Отменить», `Ctrl+Z` в Windows или `Cmd+Z` в macOS возвращает последнее действие. При возврате к незавершённому вопросу попытки команд сохраняются; на поле у такого вопроса есть отметка «продолжить».

## Проектор

**Один общий экран.** В Windows выберите «Дублировать» (`Win+P`), а в настройках дисплеев macOS включите повтор экрана. Ведущий управляет игрой с ноутбука, студенты видят то же изображение.

**Отдельный экран для студентов.** В Windows выберите «Расширить» (`Win+P`), а в настройках дисплеев macOS включите расширенный рабочий стол. В игре нажмите **«Экран для проектора»** и перенесите открывшееся окно на проектор. Основное окно оставьте на ноутбуке: там находятся кнопки ведущего и выбор команды. Студенты видят игровое поле, вопрос, счёт и результаты; правильный ответ появляется после команды ведущего. Если браузер блокирует новое окно, разрешите всплывающие окна для игры.

В обоих режимах используйте значок полного экрана в игре. В Windows также можно нажать `F11`.

## Проверка

При установленном Node.js команда `npm test` запускает проверки игровой логики.

## GitHub Pages

Адрес игры: https://edifiels.github.io/game_2/

Публикация настроена из ветки `main`, папки `/docs`. На сайт попадают только файлы игры и автономная версия `game-offline.html`. Оригинальный документ Word в репозиторий не загружается. Счёт и названия команд хранятся в браузере ведущего.

Чтобы обновить опубликованную игру после изменения исходников, выполните:

```sh
npm run build
npm test
npm run build:pages
git add .
git commit -m "Update game"
git push
```

После отправки изменений GitHub Pages обновляет сайт автоматически.
